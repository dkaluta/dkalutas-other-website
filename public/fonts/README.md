# Heebo Hebrew

`heebo-hebrew-variable.woff2` is the unmodified Hebrew subset of Heebo v28
from Google Fonts, supporting weights 100–900.

Source: https://fonts.gstatic.com/s/heebo/v28/NGS6v5_NC0k9P9H0TbFhsqMA6aw.woff2

The Unicode range in `styles/main.css` follows the Hebrew block returned by
https://fonts.googleapis.com/css2?family=Heebo:wght@100..900&display=swap.
